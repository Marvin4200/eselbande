Features

So funktioniert EselMusic

Kein Prefix, keine langen Commands — einfach tippen und Musik läuft.

⌨️
Tippen statt Commands

Einfach den Songnamen oder eine YouTube-URL in den konfigurierten Musik-Channel schreiben. EselMusic spielt ihn ab und löscht deine Nachricht automatisch — der Channel bleibt sauber.

🔁
24/7 & AutoMix

Mit /247 bleibt der Bot dauerhaft im Voice-Channel. Läuft die Queue leer, füllt AutoMix sie automatisch mit passenden Tracks nach.

📌
Live Music-Panel

Ein persistentes Embed im Musik-Channel zeigt immer den aktuellen Track — aktualisiert sich automatisch, kein manuelles Nachfragen.

🎵
Musik-Channel

Per /musicchannel set einen Text-Channel als dedizierten Musik-Channel festlegen — alle Textnachrichten dort gelten als Suchanfragen.

🔊
Powered by Lavalink

Stabile Audio-Pipeline über einen eigenen Lavalink-Node mit OAuth-authentifiziertem YouTube-Zugriff. Sauberes Streaming ohne Aussetzer, mit automatischem Fallback bei Fehlern.

Setup

In 3 Schritten startklar

EselMusic ist in unter einer Minute einsatzbereit.

1
Bot einladen

Über den „Bot einladen"-Button oben auf dieser Seite. Beim OAuth-Dialog den gewünschten Server auswählen — keine weiteren Einstellungen nötig.

2
Musik-Channel festlegen

Im gewünschten Text-Channel /musicchannel set eingeben. EselMusic postet dort das Live-Panel und behandelt alle Textnachrichten als Suchanfragen.

3
Tippen — fertig

Songnamen, YouTube-URL oder Suchbegriff in den Musik-Channel schreiben. EselMusic spielt ihn ab, löscht deine Nachricht und aktualisiert das Live-Panel.
